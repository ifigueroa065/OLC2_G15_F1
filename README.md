# OLC2_G15_F1 :skull:


### :white_check_mark: Objetivos Generales 
* Desarrollar un simulador para el lenguaje de programación ensamblador ARM64 que
abarque la fase de análisis, comprendiendo la estructura del código fuente utilizando
herramientas adecuadas para la generación de analizadores léxicos y sintácticos.

### :white_check_mark: Objetivos Específicos
* Utilizar herramientas léxicas y sintácticas, como Peggy en Javascript, para
implementar el reconocimiento y análisis del código fuente de ARM64, permitiendo al
estudiante comprender la estructura del lenguaje y su sintaxis.
* Implementar correctamente las gramáticas adecuadas para el simulador y el
correcto reconocimiento del lenguaje.
* Familiarizar al estudiante con las herramientas y estructuras de datos disponibles
para la creación de un simulador, proporcionando una comprensión profunda de los
procesos involucrados en la traducción y ejecución de programas escritos en
lenguaje ensamblador arquitectura ARM64.
